# NourishShare

## Overview
NourishShare is a full-stack web application that enables users to share and access food resources efficiently. It integrates authentication, real-time updates, payments, and location-based services.

## Tech Stack
- Frontend: React, Tailwind CSS, Vite
- Backend: Node.js, Express
- Database: MongoDB

## Features
- User authentication (JWT)
- Real-time communication (Socket.IO)
- Secure payments (Razorpay)
- Map integration (Leaflet)

## Setup
1. Clone the repo
2. Install dependencies:
   - cd project/frontend && npm install
   - cd ../backend && npm install
3. Run:
   - Frontend: npm run dev
   - Backend: npm start
